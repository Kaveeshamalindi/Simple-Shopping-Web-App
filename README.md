# Shopping Paradise 🛒

A simple shopping website created using HTML and CSS.  
This project displays products with images, prices, and **Add to Cart** buttons in a clean layout.

This project was created for learning and practicing **HTML** and **CSS** skills.

---

## 📌 Features

- Responsive product display
- Product images with borders
- Product prices
- Styled "Add to Cart" buttons
- Simple and beginner-friendly design

---

## 🛠️ Technologies Used

- HTML5
- CSS3

